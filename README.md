# 🐉 Dragon Pet — бот для Lolka

Добрый бот-дракон, который позволяет каждому пользователю **завести своего личного дракона**.

## Возможности

| Команда | Описание |
|---------|----------|
| `/dragon create <имя> [стихия]` | Завести дракона и выбрать стихию |
| `/dragon info` | Посмотреть статус своего дракона |
| `/dragon feed` | Покормить дракона |
| `/dragon play` | Поиграть с драконом |
| `/dragon daily` | Получить ежедневную награду |
| `/dragon top` | Таблица лидеров (Топ-10) |
| `/dragon rename <имя>` | Переименовать дракона |
| `/dragon release` | Отпустить дракона (с подтверждением) |

### Стихии драконов

При создании можно выбрать одну из шести стихий:

| Стихия | Эмодзи | Особенность |
|--------|--------|-------------|
| Огонь  | 🔥 | Сила пламени |
| Вода   | 💧 | Глубокие воды |
| Земля  | 🌍 | Каменная броня |
| Воздух | 🌪️ | Быстрый полёт |
| Тень   | 🌑 | Скрытность |
| Свет   | ✨ | Сияние |

Если стихию не указать — она выберется случайно.

### Эмодзи-аватары

Дракон меняет свой вид по мере роста:
- Уровень 1–4 → детёныш 🐣 + стихия
- Уровень 5–14 → молодой 🐲 + стихия
- Уровень 15–29 → взрослый 🐉 + стихия
- Уровень 30+ → древний 🔥🐉🔥 (и т.д. по стихии)

### Ежедневная награда

Раз в ~20 часов можно получить:
- +30–60 опыта
- +15–30 сытости
- +15–30 настроения

## Установка

1. Создай бота на [Lolka Developer Portal](https://lolka.app/developers/portal)
2. Включи **Message Content Intent**
3. Скопируй токен
4. Клонируй репозиторий:
   ```bash
   git clone https://github.com/dragongrok2-cloud/Dragon-Pet.git
   cd Dragon-Pet
   ```
5. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
6. Создай файл `.env`:
   ```
   BOT_TOKEN=твой_токен_бота
   ```
7. Запусти:
   ```bash
   python bot.py
   ```

## Приглашение бота

Сгенерируй ссылку в Developer Portal с правами:
- Send Messages
- Use Slash Commands
- Embed Links
- Read Message History

## Технологии

- Python 3.10+
- discord.py (работает с Lolka, т.к. API совместим)
- SQLite для хранения драконов
